# 多規則企業名稱正規化工具

這是一個以 Python 與 Streamlit 製作的企業名稱清理工具。使用者可上傳 CSV，選擇名稱欄位與正規化規則，再將清理後的名稱與既有 Excel 對照清單進行精確比對。

專案著重於處理不同國家與地區企業名稱中的法律組織型態、標點符號、大小寫及常見拼寫差異，讓名稱欄位能以較一致的格式進行對照。

## 主要功能

- 使用 Streamlit 建立檔案上傳、欄位選擇、清理方式選擇及結果預覽介面。
- 讀取 Excel 對照清單，作為標準名稱資料來源。
- 將名稱轉為大寫，並截取逗號前的主要名稱部分。
- 提供多種清理設定：移除一般公司組織型態、額外處理德國公司型態，以及納入常見錯字處理規則。
- 移除非英數字元，建立正規化名稱。
- 對正規化後的名稱進行字典式精確比對，取得對應的標準名稱欄位。
- 顯示輸入筆數與成功配對筆數。

## 操作流程

1. 載入專案中的 Excel 名稱對照清單。
2. 使用者選擇 CSV 檔案並上傳。
3. 選擇待處理的名稱欄位。
4. 選擇名稱正規化規則。
5. 系統依照所選規則清理輸入名稱與對照清單。
6. 建立正規化名稱字典並進行精確比對。
7. 顯示標準名稱對照結果及配對筆數。
